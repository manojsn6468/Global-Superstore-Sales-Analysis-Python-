# Global Superstore Sales & Profit Analysis

## Project Overview
Analyzed Global Superstore sales data using Python and Pandas to identify sales trends, profitability, and business improvement opportunities.

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Dataset
- Total Records: 51,290
- Original Columns: 27

## Key KPIs
- Total Sales: 12.64 Million
- Total Profit: 1.47 Million
- Total Orders: 25,035
- Total Quantity Sold: 178,312
- Profit Margin: 11.61%

## Analysis Performed
- Data cleaning and missing value checks
- Category and sub-category sales analysis
- Region and country performance
- Yearly sales trends
- Discount and profit analysis
- Customer segment analysis
- Data visualization using Matplotlib

## Key Business Insights
- Technology generated the highest category sales.
- Phones generated the highest sub-category sales.
- Copiers generated the highest sub-category profit.
- Tables was a loss-making sub-category.
- Central was the highest sales-generating region.
- Consumer was the highest sales-generating segment.

## Business Recommendations
- Investigate loss-making product categories.
- Review discount strategies to improve profitability.
- Focus on high-performing products and regions.

## Conclusion
This project demonstrates practical data cleaning, aggregation, business KPI calculations, exploratory data analysis, and data visualization using Python and Pandas.
